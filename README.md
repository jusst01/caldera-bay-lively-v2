Caldera Bay is an open-world crime game set in the sprawling, volcano-shadowed city of Caldera Bay.

## How to Play
- **WASD**: Drive
- **E**: Carjack / Enter car
- **F**: Fire
- **Q**: Radio
- **Esc**: Pause / Start Screen
- **B**: Job Board
- **G**: Garage

## Features
- **5 Districts**: Explore Muelle, Paseo, Verde, Ceniza, and Cumbre.
- **HEAT 1–5**: Dynamic wanted system with increasing police aggression.
- **8 Jobs**: Complete named jobs to rise through the ranks.
- **6 Respect Tiers**: From Nobody to Leyenda.
- **District Takeover**: Seize control of districts.
- **Photo Mode**: Capture your rise in Caldera Bay.

## Tech Notes
- Built with Three.js.
- Deterministic seeded world generation.
- Save system using localStorage.
